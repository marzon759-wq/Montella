# Valdoria Shaders

Shader pack for the Valdoria modpack (Iris / Oculus format, Minecraft 1.20.1).

- Sky, fog and ambient light are built from the game's own biome sky/fog colours, so every Valdoria realm and any
  other mod's biomes or dimensions get a matching atmosphere automatically.
- Soft sun shadows, sunbeams through fog and leaves, subsurface glow in foliage.
- Water: waves, fresnel sky reflections, screen-space reflections, sun glints, depth tint, shore foam, rain ripples;
  waterfalls get rushing, frothy white streaks.
- Rain: wet darkened ground and puddles that reflect the sky; translucent rain streaks; soft snow.
- Waving plants, leaves and hanging vines (vanilla and Valdoria blocks), glowing blocks with bloom, filmic tone mapping.
- Honours the game's fog distance, so realm mist (Glimmerveil Forest) and future weather like dust storms thicken it.

Install: zip the `shaders` folder (or use the release zip) into `.minecraft/shaderpacks/`, then pick it in
Video Settings → Shader Packs (needs Oculus + Embeddium on Forge).
